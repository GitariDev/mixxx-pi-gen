Actions audit · what the original menu contains

The current native Actions button opens Mixxx’s track context menu. It requires a selected track; available entries depend on the source, selection and model capabilities.

Search related / Select in Library; Auto DJ queue; Load to Deck / Sampler / Preview; Playlists and Crates; Remove from list; BPM correction / lock / reset; Rating and Color; Metadata, Cover art and web search; Clear track data; Analyze / Reanalyze; Hide / Unhide / Purge; Trash files; Open in File Browser; Properties. ReplayGain-from-pregain exists in applicable deck-widget menus, not every track table.

New primary surface: Load → Deck 1 / Deck 2; Arrange columns → persistent checkboxes and ordering; Original full menu → native commands. Show / Hide opens the file/folder pane; Sources sits at its top, above Back. No native command is deleted by this proposal. The full-menu panel here is an audit, not an operational clone.

Native Mixxx already keeps column visibility checkboxes open and supports drag ordering of headers. The touch-friendly combined arrange panel and simplified Actions entry still need native integration.
