# Six-track practice session

**Aliases:** practise, practice, learning progression, six tracks, record mix,
review transition, DJ drill

## Learning order

1. Track selection, playlist preparation, cueing, and hot cues.
2. Fade-ins, fade-outs, and EQ handoffs.
3. Looping and manual tempo correction.
4. Sampling.

Do not add the next layer until the earlier transition can be repeated without
watching the waveform continuously.

## Session

1. Prepare six compatible tracks with a manageable BPM range.
2. Apply the same four-hot-cue system to each track.
3. Practise cueing and launching on 32-beat phrase boundaries.
4. Record five basic fades without loops.
5. Repeat them using one 8- or 16-beat loop.
6. Practise manual jog/tempo correction even when Sync is available.
7. Add no more than one sample to each transition.
8. Review the recording for phrase errors, clashing vocals, double basslines, clipping, and abrupt level changes.

## Combo drills

- **Standard:** compatible selection, Pad 1 launch, long fade, bass handoff, A out.
- **Extended Blend:** loop B intro, match, fade in, bass handoff, release loop, A out.
- **Emergency Recovery:** jump A to Pad 4 or loop its outro, cue B, Safe Launch, A out.
- **Drop Combo:** cue B at Pad 3, loop/fade A's last phrase, trigger a riser, launch B's drop on the next `1`.
- **Tempo Bridge:** choose an intermediate track, loop a stable section, move BPM gradually, phrase-match, and fade into the new range.

## Journal the result

- Date and playlist version
- Transitions attempted and successful
- Grid/cue corrections needed
- Audio, controller, temperature, or power faults
- One technique to retain and one to simplify next time
